# 输出：不生成知识卡片

> 来源：tests/samples/04-thin.md ｜ 识别知识点 0 个 ｜ 成卡 0 张

## 为什么不出卡

这篇是资讯型报道，通篇是“发生了什么”，没有“为什么会这样 / 该怎么做 / 在什么条件下成立”。按卡片标准，可成卡的内容为零：

| 原文内容 | 为什么不能成卡 |
| --- | --- |
| 售价 499 元、11 月 1 日发货、三种配色 | 事实罗列，无解释、无机制，读完不改变任何判断 |
| “语音唤醒速度有明显提升” | 原文自述未公布测试数据，无法验证，写成卡片等于替厂商背书 |
| 会员年费 99 元，含有声书和儿童内容 | 同上，属产品信息而非知识 |
| “分析师认为价格是主要竞争手段” | 未给出分析师身份、依据或数据，属无支撑的第三方观点 |
| “能否获得市场认可，仍有待观察” | 无信息量的套话 |

## 不这样做的原因

用这篇凑出 5 张卡是可行的——把“三种配色”写成一卡、把“会员服务”写成一卡、把“分析师观点”扩写成一卡。但那样产出的卡片既不能复习也不能自测，只是把一段短讯换了排版，还夹带了原文没有的解读。这违反两条底线：一张卡一个知识点、不编造原文没有的信息。

## 可以改做什么

- 如果你要的是**信息摘要**：可以直接给一条 3 行的要点摘要，不套卡片格式。
- 如果你要的是**可复习的知识**：需要一篇有解释的材料，比如智能音箱的语音唤醒为何受限于麦克风阵列与降噪算法、硬件补贴加内容订阅的商业模式如何成立。给我这类文章，我再切卡。
